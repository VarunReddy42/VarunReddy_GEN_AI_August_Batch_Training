# SmartHire GenAI — Evaluation Report

This file is auto-generated by running:

```bash
python -m src.evaluate
```

It will overwrite this file with real results covering:

1. **Retrieval relevance** — hit rate across test candidate profiles
2. **Answer quality** — LLM-as-judge scores (correctness, groundedness,
   helpfulness) for a set of mentor questions
3. **Prompt comparison** — the v0 (baseline) vs v1 (current) CV-suggestions
   prompt, side by side, showing why the stricter v1 prompt produces
   more usable output
4. **Hallucination check** — confirms the mentor refuses to answer a
   question with no support in the career-notes corpus, rather than
   inventing an answer

Run it once your job index and career-notes index are built (see the
main README), with a working Gemini API key in `.env`.
